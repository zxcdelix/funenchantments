# funenchantments
Fun Enchantments adds a collection of powerful and useful enchantments for mining, digging, chopping, and tool management. It expands vanilla progression with enchantments such as Auto Smelt, Magnet, Drill, Scan, Lumberjack, Filter, and more. It also increases the maximum levels of several vanilla enchantments to make late-game tools more exciting.


Features
Upgraded Vanilla Enchantments

    Efficiency up to level X
    Fortune up to level V
    Unbreaking up to level V

New Tool Enchantments

Auto Smelt Automatically smelts block drops when mining. For example, ores can turn directly into ingots if they have a smelting recipe.

Magnet Sends block drops directly into your inventory instead of dropping them on the ground.

Filter I–III Helps manage a full inventory while mining. If your inventory is full, the enchantment can automatically throw away common trash blocks such as cobblestone, dirt, gravel, deepslate, netherrack, and similar blocks. Higher levels can remove more trash stacks.

Drill I–II Mines multiple blocks at once.

    Level I: mines a 3x3x1 area
    Level II: mines a 3x3x3 area

Scan I–III When you mine an ore, nearby matching ore blocks are highlighted with particles for a short time.

    Level I: radius 2 blocks
    Level II: radius 3 blocks
    Level III: radius 5 blocks

Lumberjack I–II Axe enchantment for cutting trees faster.

    Level I: cuts small trees
    Level II: cuts much larger trees

Forester's Fortune I–V Axe enchantment that gives a chance to receive extra wood when chopping logs.

Digger's Fortune I–V Shovel enchantment that gives a chance to receive extra drops when digging.

Pinger Warns you when your tool durability is low. If an expensive tool is almost broken, Pinger can block mining to help save it.
Compatibility

Fun Enchantments is designed to work with Fabric modpacks and supports both singleplayer and multiplayer.

The mod uses common ore tags where possible, so ore-related features can work with many modded ores if those mods use standard tags.
Enchanting and Loot

The enchantments can appear in the enchanting table and may also be found as enchanted books in loot.
Important Notes

This mod should be installed on both the client and the server.

For multiplayer servers, the mod is required server-side for the enchantment logic to work correctly. Installing it on the client is also recommended for proper names, data, and compatibility.
